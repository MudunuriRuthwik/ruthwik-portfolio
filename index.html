PlacementSense AI

PythonScikit-learnFlask

A web app that predicts a student’s placement outcome from academic and personal attributes.

  • Trained and compared Logistic Regression, SVM and Random Forest after scaling and encoding the features.

  • Connected the model to a Flask backend. The result page shows probability, risk level, strengths and recommendations.

EcoDrive AI

Random ForestLinear RegressionOpenRouteService APIFlask

Predicts vehicle mileage and CO2 emissions, and compares routes by distance and estimated emissions.

  • Random Forest for mileage prediction, Linear Regression for emission estimates.
  • Integrated the OpenRouteService API for route data and alternative-route comparison.
  • Wired the models into backend logic so one request returns vehicle and route insights together.
Relevance: Ather works on vehicles. This project shows I can connect a model to a live external API and present trade-offs side by side.
